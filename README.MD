# PG ESTATE 

The project is a Real Estate based project for Students mostly used for Post Gradudates hence the term PG Estate,it is PERN Stack which utilizes techonologies such as React for frontend, PHP(along with ajax for asynchronous request) and javascript for backend and Mysql for Databases.
This project was made as an assignment project for the Web Development Course completed in March 2024.

### Features Includes :
- Search (Ajax call used)
- Sorting (Based on rent amount)
- Filter (based on gender type)
- Favourites (For Interested Properties as saved later)
- Appropiate Breadcrumbs
- Add and View Reviews (Displayed from Databse)
- SignIn and SignOut (using appropiate sessions in php namely phpsessionid)
